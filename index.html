Projects A selection of my data science and machine learning work spanning healthcare, NLP, and data engineering.

NVDA Automatic Image Caption

This project focused on developing an AI-powered image captioning system for NVDA (NonVisual Desktop Access) to improve accessibility for individuals with visual impairments. The work involved researching existing machine learning approaches, processing and training on large-scale image–caption datasets, and building deep learning models using CNNs to generate accurate image captions. The project's impact lies in making digital content more accessible by helping users better understand and interact with images through automatically generated descriptions.

InboxIntel

This project, InboxIntel, focused on developing a machine learning system to automatically detect spam emails and identify the keywords most indicative of malicious or fraudulent content. Using a large-scale dataset of over 82,000 emails collected from multiple public corpora, the project involved cleaning and analyzing email text data, applying natural language processing techniques, and training predictive models including Naive Bayes, Logistic Regression, and Neural Networks. The project's impact lies in strengthening cybersecurity efforts by improving automated spam detection and helping protect users from phishing attempts, fraud, and other malicious online threats.

Summify

This project, Summify, focused on developing an AI-powered platform that automatically extracts and synthesizes information from audio and video content to save users time and improve accessibility through API calls. The system was designed to generate concise summaries, identify key points, extract major topics, and perform sentiment analysis across various audio and video formats. The project's impact extends beyond productivity by improving accessibility for individuals with hearing impairments, making information from audio and visual media easier to consume and understand.
